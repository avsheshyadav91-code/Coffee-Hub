# CoffeeHub - Premium Coffee Landing Page

A modern, fully responsive landing page for a premium coffee brand built with HTML, CSS, and vanilla JavaScript.

## 🌟 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode Toggle** - Users can switch between light and dark themes with persistent storage
- **Animated Elements** - Scroll reveal animations, typewriter text effect, and smooth transitions
- **Interactive Counters** - Animated statistics that count up on scroll
- **Mobile Navigation** - Hamburger menu for mobile devices with smooth animations
- **Modern UI/UX** - Premium styling with gradients, shadows, and hover effects
- **Accessibility** - Semantic HTML with ARIA labels and proper contrast ratios
- **Performance** - Optimized images and efficient JavaScript

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling with Flexbox, Grid, and animations
- **JavaScript** - Vanilla JS for interactivity (no frameworks)
- **Google Fonts** - Poppins font family

## 📋 Sections

1. **Navigation Bar** - Sticky navbar with logo, links, theme toggle, and mobile menu
2. **Hero Section** - Eye-catching headline with CTA buttons and hero image
3. **Statistics** - Animated counter cards showcasing key metrics
4. **Menu** - Product cards displaying popular coffee items
5. **About** - Company story with feature list
6. **Testimonials** - Customer reviews and feedback
7. **CTA Section** - Limited time offer promotion
8. **Footer** - Copyright and contact information

## 🎨 Design Highlights

- Premium warm color palette (coffee/brown/cream tones)
- Smooth scroll behavior and reveal animations
- Hover effects on interactive elements
- Professional typography and spacing
- Gradient backgrounds and modern shadows
- Dark mode with carefully chosen colors

## 📱 Responsive Breakpoints

- Desktop: 1200px and above
- Tablet: 768px - 991px
- Mobile: Below 768px
